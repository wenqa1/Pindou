# 在线图纸库接口契约

文档版本：0.1  
契约版本：v1  
首版协议：公开、只读、HTTPS、签名静态清单 + CDN 不可变资产

## 1. 设计原则

- 客户端不登录，公共读取接口不返回用户数据。
- 首版目录通过静态 CDN 资源交付，保持与 REST 资源命名一致。
- 1.0 静态资源使用本章固定的裸 JSON/压缩字节格式；未来动态 API 才使用统一响应和错误结构。
- 大文件由 CDN 直接下载，不经过应用 API 代理。
- 目录、图纸版本和内容包不可变；更新创建新 URL。
- `latest`/频道指针支持 ETag 条件请求，资产使用长缓存。

## 2. 1.0 唯一 Wire Format

每个需要签名的文件 `FILE` 都有同路径伴随文件 `FILE.sig`：

```json
{
  "algorithm": "Ed25519",
  "keyID": "KEY_ID",
  "sha256": "HEX_OF_EXACT_FILE_BYTES",
  "signature": "BASE64_SIGNATURE_OF_EXACT_FILE_BYTES"
}
```

客户端先校验 `.sig` 结构和内置公钥，再验证实际下载原始字节的 SHA-256 和 Ed25519 签名。JSON 不重新序列化后验证，避免规范化歧义。缺签名、未知 key、签名失败或摘要不符均拒绝。

### 2.1 稳定频道

`GET /content/v1/channels/stable.json`  
`GET /content/v1/channels/stable.json.sig`

用途：返回当前有效目录版本、撤回清单和兼容信息。支持 `If-None-Match`，未变化返回 `304 Not Modified`。

响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| schemaVersion | integer | 响应结构版本 |
| catalogVersion | string | 当前不可变目录版本 |
| sourceMode | enum | 1.0 固定为 `static` |
| catalogManifestURL | string | 目录 manifest 地址 |
| revocationChannelURL | string | 独立撤回频道地址 |
| publishedAt | ISO-8601 | 发布时间 |
| minimumAppVersion | string | 最低兼容 App 版本 |
| catalogManifestSHA256 | hex string | 目录 manifest 原始字节摘要 |

缓存：`Cache-Control: max-age=300, stale-while-revalidate=86400`，必须返回 ETag。

频道文件是裸 JSON；签名位于伴随 `.sig` 文件，不使用 `data` 包裹。

### 2.2 目录 manifest 与分片

`GET /content/v1/catalogs/{catalogVersion}/manifest.json`  
`GET /content/v1/catalogs/{catalogVersion}/manifest.json.sig`

manifest 是裸 JSON，固定包含：schemaVersion、catalogVersion、publishedAt、entryCount，以及有序 `shards` 数组。每个 shard 包含 URL、字节数、SHA-256、条目数、首尾稳定 ID。manifest 使用分离签名。

`GET /content/v1/catalogs/{catalogVersion}/shards/{number}.json.gz`

- shard 是 UTF-8 JSON 数组经确定性 gzip 后的实际传输字节。
- manifest 中 SHA-256 覆盖实际下载的 `.json.gz` 字节，不是解压后的 JSON。
- shard 本身无需单独签名，因为其摘要被已签名 manifest 覆盖。
- 分片顺序只以 manifest 数组为准；全部 shard 校验后才切换目录。

目录 manifest 和 shard 均不可变：

`Cache-Control: public, max-age=31536000, immutable`

CatalogEntry 的机器可验证 JSON Schema 是字段真值源；《在线图纸库架构》只解释语义。客户端忽略未知可选字段，对未知必需 Schema 版本拒绝。

### 2.3 图纸详情

`GET /content/v1/patterns/{patternId}/versions/{version}/manifest.json`  
`GET /content/v1/patterns/{patternId}/versions/{version}/manifest.json.sig`

返回裸 JSON，包含许可、署名、包大小、内容摘要和兼容信息，并强制分离签名。manifest 中内容包/图片的 SHA-256 覆盖实际下载字节。

### 2.4 内容包和资产

- `GET /content/v1/packages/{sha256}.bundle`
- `GET /content/v1/assets/{sha256}/{variant}`

资产 URL 由 manifest 给出。客户端允许 HEAD/GET、Range 和断点续传，不把目录中的任意外部 URL 当作可信资源。

### 2.5 撤回清单

`GET /content/v1/revocations/stable.json`  
`GET /content/v1/revocations/stable.json.sig`  
`GET /content/v1/revocations/{version}.json`  
`GET /content/v1/revocations/{version}.json.sig`

撤回频道指向不可变撤回清单，两者都是裸 JSON 并强制分离签名。条目：patternId、patternVersion、action、reasonCode、effectiveAt、replacementPatternId。撤回不可通过“目录条目消失”隐式表达。

### 2.6 静态错误响应

静态 CDN 资源以 HTTP 状态为准；错误正文不属于协议，客户端不得尝试解析为 API 错误对象。404 表示资源不存在，410 表示明确撤回，429/503 遵循 Retry-After。

## 3. 第二阶段动态查询 API

仅在目录规模或搜索性能达到架构演进门槛后启用：

### 3.1 图纸列表与搜索

`GET /api/v1/patterns`

查询参数：

| 参数 | 说明 |
|---|---|
| q | 标题、作者、标签规范化搜索 |
| category | 分类，可多值 |
| palette | 色卡标识 |
| difficulty | 难度 |
| rowsMin/rowsMax | 行数范围 |
| columnsMin/columnsMax | 列数范围 |
| colorsMax | 最大颜色数 |
| sort | `-publishedAt`、`title`、`difficulty` |
| cursor | 不透明游标 |
| limit | 默认 30，最大 100 |

成功响应：`data`、`meta.hasNext`、`meta.nextCursor`、`links.self/next`。游标编码排序字段与稳定 ID，客户端不得解析。

### 3.2 分类和筛选元数据

- `GET /api/v1/categories`
- `GET /api/v1/palettes`

这些资源版本化并支持 ETag。

## 4. 动态 API 响应格式

本节仅适用于第二阶段 `/api/v1/` 动态 API，不适用于 `/content/v1/` 静态资源。

成功单资源：

```json
{
  "data": {
    "id": "PATTERN_ID",
    "version": "1.0.0"
  }
}
```

错误：

```json
{
  "error": {
    "code": "resource_not_found",
    "message": "The requested pattern does not exist.",
    "requestId": "REQUEST_ID",
    "details": []
  }
}
```

错误消息不暴露存储路径、堆栈、SQL 或签名密钥信息。

## 5. HTTP 状态

| 状态 | 用途 |
|---|---|
| 200 | 正常读取 |
| 206 | Range 部分内容 |
| 304 | 条件请求未变化 |
| 400 | 查询格式错误 |
| 404 | 资源不存在 |
| 410 | 已撤回且不再分发 |
| 422 | 参数语义无效 |
| 429 | 超过读取频率限制 |
| 500 | 未预期错误 |
| 503 | 临时不可用，携带 Retry-After |

## 6. 限流与重试

- 公共元数据接口按 IP/边缘策略限流；正常浏览不应触发。
- `429` 和 `503` 返回 `Retry-After`。
- 客户端只对超时、连接中断、429 和 5xx 做有上限的指数退避；400、404、410、422 不自动重试。
- 用户主动下载优先于预取；应用进入后台后停止目录预取。

## 7. 缓存契约

| 资源 | 缓存 |
|---|---|
| 频道指针/撤回频道 | 5 分钟 + ETag + stale-while-revalidate |
| 目录 manifest、shard、图纸 manifest | 1 年 immutable |
| 内容包/图片 | 1 年 immutable，URL 含内容哈希 |
| 410 响应 | 短缓存，避免长期错误固定 |

客户端以响应中的 ETag/哈希为准，不用文件路径或标题作为缓存键。

## 8. 管理与发布接口边界

首版不开放运行时写 API。内容通过受控仓库/表单进入校验、审核、打包、签名和发布流水线。

如果后续建设管理 API，使用独立主机和 `/admin/v1/` 命名空间，强制身份认证、角色权限、审计日志和幂等键；管理接口不暴露给 App，也不与公共 CDN 凭据共用。

## 9. 兼容与弃用

- 非破坏性新增字段不升级 API 主版本。
- 删除/重命名字段、改变类型、签名语义或包结构需要新主版本。
- 客户端至少支持当前和上一目录 Schema；更旧版本通过频道指针停止发布。
- 动态 API 启用后，静态目录只作应急快照，不作为第二真值。

## 10. 契约验收

- OpenAPI/JSON Schema 或等价机器可验证 Schema 与示例同步。
- 目录、详情、包和撤回清单执行消费者契约测试。
- 相同 URL 永不返回不同字节。
- 304 不触发目录数据库写入。
- 分页过程中插入新条目不造成当前游标重复或遗漏已排序范围。
- 内容包校验失败时不产生本地图纸、下载完成记录或库存变化。
