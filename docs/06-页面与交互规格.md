# 页面与交互规格

文档版本：0.1  
适用平台：iOS/iPadOS 16+  
原则：iPhone 与 iPad 功能一致，iPad 使用更高信息密度和多栏布局；所有核心操作离线可用。

## 1. 导航结构

底部一级导航固定为：首页、图纸、辅助拼豆、豆仓、我的。

| 一级页 | iPhone | iPad |
|---|---|---|
| 首页 | 单列信息流 | 双列仪表盘，左侧继续拼，右侧库存/补货 |
| 图纸 | 列表进入详情 | 侧栏筛选 + 图纸列表 + 详情三栏 |
| 辅助拼豆 | 画布全屏、底部工具栏 | 画布居中、左侧任务、右侧色号检查器 |
| 豆仓 | 色板/列表切换 | 左侧筛选、中央色板、右侧色号详情 |
| 我的 | 分组设置列表 | 设置侧栏 + 详细配置页 |

全局“+”菜单提供上传图纸、空白图纸、入库、盘点。iPad 支持键盘快捷键 `⌘N` 打开菜单，具体子操作通过二级快捷键选择。

## 2. 首页

### 2.1 内容顺序

1. 继续拼：最近一个制作会话、进度和继续按钮。
2. 库存提醒：低库存、在途可覆盖、仍需采购三类数量。
3. 可拼图纸：按当前可用库存计算的本地图纸。
4. 最近图纸与完成作品。
5. 在线图纸库推荐、最新和分类入口；无网络时显示内置启动集与已缓存目录。

### 2.2 状态

- 首次使用：显示“初始化色卡”“导入第一张图纸”两个并列任务。
- 无制作会话：继续拼卡片改为“选择图纸开始”。
- 库存未初始化：不显示虚假 0 库存警报，显示初始化引导。
- 飞行模式：页面结构不变；在线卡片显示“离线内容/上次更新”，本地功能不显示全局网络错误横幅。

## 3. 豆仓

### 3.1 库存总览

- 顶部摘要：现存、可用、在途、低库存色号数。
- 视图切换：色板、列表；筛选：品牌、系列、尺寸、色系、状态。
- 色板格同时显示色号与数量；低库存使用图标和文字，不只使用红色。
- 长按色号提供快速入库、出库、设阈值、查看流水。

### 3.2 色号详情

iPhone 使用下钻页；iPad 在右侧检查器显示。

- 顶部：色块、品牌/系列/色号、现存/预留/可用/在途。
- 中部：7/30/90 天消耗图和关联图纸。
- 底部：流水时间线，支持筛选。
- 主操作：入库、出库；次操作：盘点、阈值、导出明细。

### 3.3 入库/出库表单

- SKU 支持色号搜索和最近使用。
- 数量键盘只允许正整数；粘贴非法值时就地提示。
- 提交前显示余额变化，例如 `8,500 → 10,500`。
- 提交成功显示单号和“查看流水”；重复点击确认只生成一张单。

## 4. 图纸库与详情

图纸一级页分为“在线发现”和“我的图纸”。在线发现需要网络更新，但可使用上次目录；我的图纸始终离线可用。

### 4.1 图纸库

- 筛选：全部、待校对、可拼、缺豆、制作中、已完成、归档。
- 排序：最近修改、创建时间、尺寸、豆数、完成度。
- 多选模式提供消耗计算、打标签、归档、删除。
- 图纸卡显示缩略图、行列、总豆数、颜色数、可拼状态和制作进度。

### 4.2 在线发现

- 顶部：搜索、分类、最新、推荐；筛选尺寸、难度、颜色数、色卡和可拼状态。
- 卡片显示在线/已下载/有更新/已下架状态、作者、许可摘要和下载大小。
- 搜索使用本机目录索引；输入后 250 ms 执行，可取消旧查询。
- 目录刷新使用后台差量更新；首次进入立即显示本地快照，不等待网络。
- 无目录缓存时显示内置启动图纸和“联网刷新”按钮。

### 4.3 在线详情与下载

- 详情显示预览、作者、来源、许可、署名、版本、尺寸、用量、库存可拼判断和下载大小。
- 下载状态：排队、下载中、暂停、校验、安装、失败、已下载、可更新、不兼容、已下架。
- 用户主动下载离开页面后继续；预取离开可见范围后取消。
- 校验完成前不出现“开始拼”；安装完成后可离线打开。
- “开始拼/编辑”创建本地用户副本，远端更新不改变当前项目。
- 下架内容显示原因类别和替代版本；不得删除库存流水或已完成记录。

### 4.4 本地图纸详情

- 顶部预览支持网格、色号、豆板边界和镜像切换。
- 信息区显示版本、尺寸、总豆数、颜色数、库存结论。
- 用量清单逐色展示需求、可用和缺口。
- 主按钮按状态变化：继续校对、开始拼、继续拼、查看成品。
- “更多操作”：编辑、复制版本、消耗计算、完成并出库、导出、归档、删除。

## 5. 上传图纸向导

向导顶部显示 1–7 步和当前步骤名称，底部固定“上一步/继续”。所有步骤自动保存草稿。

| 步骤 | 页面重点 | 继续条件 |
|---|---|---|
| 1 获取素材 | 相册、文件、相机、系统分享、链接文本 | 至少获得一个本地图片候选 |
| 2 选择图片 | 主图/镜像候选、裁剪、旋转 | 选择有效图片 |
| 3 框选图例 | 可移动/缩放框，支持“无图例” | 有框选区或明确选择无图例 |
| 4 核对总数 | OCR 结果、候选和手动输入 | 数量合法或标记图纸无总数 |
| 5 校准网格 | 四角、行列、九宫格锚点、局部放大 | 四边覆盖且行列确定 |
| 6 有效图纸 | 裁掉说明区，预览豆板分区 | 有效区至少 1×1 |
| 7 识别校对 | 异常列表、色号候选、总数差异 | 无未处理阻断项并由用户确认 |

### 5.1 网格校准交互

- 四角拖点控制透视；边缘中点控制有效范围。
- 行列数可直接输入；系统实时叠加格线。
- 局部放大镜显示当前交点前后各 4 格，形成约 8×8 校准窗口。
- 误差面板显示左/右/上/下残差，不使用模糊的“识别失败”。
- iPad 支持 Apple Pencil 精细拖动；手指用于平移缩放。

### 5.2 识别校对交互

- 左侧/底部为画布，右侧/上拉面板为异常项。
- 点击异常项定位具体格子或图例行。
- 色号显示“图例确定”“色卡推测”“用户指定”。
- 修改映射后即时更新逐色数量、总数差异和库存结论。
- “确认保存”前展示摘要：行列、非空格、颜色数、人工修正数。

## 6. 辅助拼豆

### 6.1 画布层级

从下到上：底色、豆格颜色、普通网格、豆板边界、进度遮罩、高亮/蚂蚁线、坐标与选择框。各层可独立开关。

### 6.2 工具布局

- iPhone：顶部项目状态，中央画布，底部颜色条与工具栏。
- iPad：左侧板块/任务，中央画布，右侧颜色与设置；三栏可收起。
- 常用工具保持一层可达：撤销、重做、高亮、完成标记、视图、设置。

### 6.3 手势与快捷键

| 操作 | 手势 | 键盘 |
|---|---|---|
| 平移 | 双指或空白区拖动 | 空格 + 方向键 |
| 缩放 | 双指捏合 | `⌘+` / `⌘-` |
| 标记单格 | 单击/Pencil 点按 | Return |
| 框选 | 长按后拖动/Pencil 拖动 | Shift + 方向键 |
| 撤销/重做 | 工具栏 | `⌘Z` / `⇧⌘Z` |
| 切换下一色 | 色号栏点击 | Tab |
| 显示原图 | 按住对比按钮 | `O` 按住 |

### 6.4 防误触

- 单格完成允许立即撤销。
- 区域完成、整色完成和完成图纸需要二次确认并显示影响格数。
- 画布编辑与进度标记使用不同模式和明显工具栏状态。
- 退出时无需手动保存；写入失败才显示阻断提示。

## 7. 消耗计算与补货

- 顶部显示选中图纸数、需求总数和缺货色号数。
- 每行固定列：SKU、需求、现存、预留、可用、在途、现货缺口、预计缺口。
- iPhone 以两行卡片呈现，iPad 使用可排序表格。
- 底部操作：生成预留、生成补货单、复制清单。
- 补货文本导入分为粘贴、解析预览、确认写入三步；任何歧义项保持未选中。

## 8. 设置与本地数据

- 色卡管理：启用品牌/系列、自定义颜色、色卡版本。
- 默认阈值、默认豆板、默认拼制模式。
- 内置内容：查看版本、许可和占用空间。
- 数据：导出备份、导入备份、最近删除、清理缓存。
- 在线图纸库：目录更新时间、仅 Wi‑Fi 下载、下载队列、已下载占用、图片缓存上限和清理。
- 隐私：权限状态和本地处理说明。
- 关于：版本、开源许可、反馈方式。

## 9. 通用反馈规范

- 成功：短暂反馈并保留可追踪入口，不用打断式弹窗。
- 可恢复错误：说明发生位置、保留用户输入、提供重试。
- 数据风险操作：显示对象、影响数量和恢复方式。
- 长任务：显示阶段、进度、取消；进入后台后恢复状态。
- 空状态必须给出一个主操作，不使用纯说明页面。

## 10. 原型验收清单

- iPhone 和 iPad 均能走通“初始化库存—上传图纸—校准—辅助拼制—出库—补货”。
- iPad 三栏布局在 1/2 分屏时正确退化。
- 任何库存变化在确认前都能看见前后余额。
- 识别不确定性始终可见，用户能定位并修改。
- 核心操作不依赖网络或账号。
- 颜色状态同时有色号、文字或符号表达。
