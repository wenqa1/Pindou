# 豆图产品需求文档（PRD）

文档版本：0.1  
目标平台：iOS/iPadOS 16+，iPhone 与 iPad 通用应用，重点适配 iPad  
产品形态：原生应用；最终可通过 TestFlight、App Store 或受控设备分发  
首发语言：简体中文

系统约束：识别、色彩匹配、库存、统计、补豆文本解析和制作均在本机完成；在线图纸库仅用于目录发现和内容下载，不接入通用大模型或云端推理。已下载图纸可离线使用。

## 1. 产品目标

### 1.1 产品愿景

让用户从“看到一张想拼的图”到“准备齐豆子并完成作品”的全过程都在一个应用内完成，且库存和制作进度始终准确、可追溯。

### 1.2 核心指标

| 指标 | 首发目标 |
|---|---:|
| 图纸首次导入完成率 | 在 1,000 次“选择有效本地图片”会话中，10 分钟内保存确认图纸的比例 ≥ 85% |
| A 类带图例规则网格图：人工校准后网格准确率 | Beta ≥ 99.5% |
| 错误图被误标为“完全正确”的比例 | Beta ≤ 0.2% |
| 图纸统计总豆数与最终网格非空格数一致率 | 100% |
| 出库后库存账实计算一致率 | 100% |
| 辅助拼豆会话恢复成功率 | 1,000 次强制终止样本中，恢复到最后完整进度块的比例 ≥ 99.5% |
| P0 会话崩溃率 | TestFlight 有效 P0 会话中发生崩溃的会话比例 < 0.2% |
| 首次用户完成“导入—可拼判断—开始拼制”中位时长 | ≤ 5 分钟 |

### 1.3 目标用户

- 有多色、多品牌豆子，需要长期管理库存的拼豆爱好者。
- 从短视频/图文平台收集图纸，需要快速导入和校对的用户。
- 制作 52 钉以上大图，需要分板、辅助线和进度记录的用户。
- 同时规划多个作品或系列，需要提前算豆和补货的用户。

### 2.2 外部链接功能边界

- 链接提取只是可选的图片来源适配器；成功下载到本地图片后，才进入统一识别管线。
- 仅支持列入白名单且允许访问的来源、图片 MIME 类型和大小范围。
- 链接不可用、需要登录或来源规则变化时，保留 URL 并引导使用系统分享图片、截图或文件。
- 应用不建设中转服务，不承诺解析任意网页。

### 2.3 首版不做

- 未取得许可的第三方 IP 图纸聚合。
- 依赖非公开接口的固定平台抓取。
- 自动下单或代用户付款。
- 未经用户确认的自动替换色号、自动扣库存。

## 3. 信息架构

底部导航建议为五个一级入口：

1. **首页**：继续拼、待补货、可拼图纸、最近作品、在线推荐。
2. **图纸**：在线发现、我的图纸、已下载、待校对、可拼、缺豆、制作中、已完成。
3. **辅助拼豆**：最近会话、按板/按颜色任务、进度。
4. **豆仓**：库存、流水、消耗统计、补豆清单、在途。
5. **我的**：品牌色卡、备份导入导出、隐私、订阅与帮助。

全局右上角“+”提供：上传图纸、空白创作、入库、快速盘点。

## 4. 核心对象与术语

| 术语 | 定义 |
|---|---|
| 色卡 | 某品牌/系列的全部颜色定义 |
| SKU | 品牌 + 系列 + 尺寸 + 色号的唯一组合 |
| 现存量 | 已到货入库减去已确认出库后的账面数量 |
| 预留量 | 已分配给未完成图纸、暂未实际出库的数量 |
| 可用量 | `max(现存量 - 预留量, 0)` |
| 在途量 | 已下单但未确认到货的数量 |
| 预计可用量 | `可用量 + 在途量` |
| 图纸用量 | 图纸中映射到某 SKU 的有效网格数 |
| 缺口 | `需求量 - 可用量`，大于 0 时为现货缺口 |
| 预计缺口 | `需求量 - 预计可用量`，大于 0 时为到货后仍缺 |
| 台账流水 | 导致库存变化或预留变化的不可静默删除记录 |

## 5. 功能需求

### 5.1 豆仓与库存管理

#### 5.1.1 库存总览

- 按品牌、系列、尺寸、色系、库存状态筛选。
- 色号卡片显示实物近似色、色号、现存、可用、在途和阈值状态。
- 支持列表/色板视图；支持按色号、名称搜索。
- 顶部显示：现存总颗数、可用总颗数、在途总颗数、低库存色号数。
- 库存状态：充足、接近阈值、低库存、无库存、在途可覆盖、仍需采购。

#### 5.1.2 色号详情

- 显示当前余额、预留、在途、累计入库、累计出库、近 30/90 天消耗。
- 流水按时间倒序，支持类型、项目、日期筛选。
- 每条记录包含：类型、数量、前后余额、来源、关联图纸/采购批次、备注、时间。
- 错误流水通过“冲销并重做”纠正，保留原记录和关联关系。

#### 5.1.3 入库、出库、盘点

- 手动入库：选择 SKU、数量、到货日期、单价/供应商（可选）、备注。
- 手动出库：选择 SKU、数量、用途/图纸、备注；余额不足时阻止确认或要求用户选择“记为缺口”，不得产生未知负库存。
- 盘点：输入实盘数量，系统生成差异调整记录。
- 批量操作支持粘贴文本和表格导入，提交前必须展示解析预览与错误项。

#### 5.1.4 常用色与消耗统计

- 时间范围：7 天、30 天、90 天、本年、自定义。
- 排名口径可切换：消耗颗数、出库次数、涉及图纸数。
- 展示入库、出库、净变化、剩余总库存、低库存趋势。
- 可按品牌/系列过滤；统计口径和时区固定显示。

### 5.2 上传图纸

#### 5.2.1 图纸来源

- 图纸库：内置启动集和在线目录；支持分类、关键词、尺寸、颜色数、难度、色卡和可拼状态筛选。
- 本地来源：相册、文件、相机扫描、系统分享扩展。
- 链接来源：粘贴公开链接或从其他 App 分享到本应用。
- 导入失败时保留链接和失败原因，允许改用截图/图片继续，不丢失已填写元数据。

#### 5.2.2 导入向导

流程固定为可回退的七步：

1. **获取素材**：显示可用图片候选、分辨率和来源。
2. **选择图片**：主图/镜像图/其他候选，支持裁剪和旋转。
3. **框选图例**：框选左上角或任意位置的色号—数量区域。
4. **核对总数**：识别标注总数；若没有标注则标记“待与网格统计比对”。
5. **校准网格**：自动建议格数、透视纠正、九宫格/自定义锚点，支持 8×8 等局部放大校准。
6. **框选有效图纸**：检查四边、行列和豆板边界。
7. **识别与校对**：生成色号、数量、置信度和异常清单，用户确认后保存。

每一步自动保存草稿。退出后从上次步骤继续。

#### 5.2.3 识别规则

- 导入后先分为：带图例彩色网格、无图例彩色网格、硬边像素图、普通照片/插画、代码型网格；各类型使用独立流程。
- 识别结果必须绑定一个品牌/系列；无法确定时要求用户选择色卡。
- 图例 OCR 与网格颜色聚类分别运行，再按色号候选进行匹配。
- 带图例图纸优先在同一张图片内匹配“格子颜色 → 图例色块 → 色号”，降低屏幕偏色影响；无图例图纸才直接匹配品牌色卡。
- 自动结果标记为“图例确定”“色卡推测”或“用户指定”，不得把推测结果显示为确定结果。
- 校验式：`所有色号用量之和 = 有效非空网格数`。
- 若图纸标注总数存在，则同时校验：`识别网格总数 = 标注总数`。
- 差异不为 0 时不得显示“已完全校对”，需定位可能的漏格、边界或 OCR 异常。
- 低置信度色号、未匹配颜色、重复色号、异常数量单独列出。

详细算法边界、数据集和验收指标见《图纸识别逻辑与可行性验证》。

#### 5.2.4 人工校对

- 修改色号、数量或颜色映射时即时重算总数与库存差额。
- 支持点击网格查看坐标和当前色号，框选区域批量调整。
- 保存前展示版本摘要；原始图、裁剪参数、网格参数和识别结果均保留，支持重新识别。

### 5.3 图纸编辑与辅助拼豆

#### 5.3.1 画布与豆板

- 常用豆板预设：52、78、104、120 钉；允许自定义行列。
- 支持横竖方向、多个豆板拼接、辅助线移动和吸附。
- 辅助线显示实体板编号、局部坐标与全局坐标。
- 缩放时网格、色号文字和进度标记按阈值分级显示，避免过密。

#### 5.3.2 拼制模式

- 按颜色：一次聚焦一个或多个色号。
- 按豆板：一次聚焦一个板块。
- 边框优先：先显示每个连通区域的边界，再显示内部。
- 自定义任务：用户框选区域和颜色组合。
- 设置项：色号多选、点击色号切换高亮、蚂蚁线速度/粗细、邻色淡化程度、屏幕常亮、左/右手布局。
- 非目标颜色可淡化但不消失；用户可随时切换“原图/高亮/进度”视图。

#### 5.3.3 进度记录

- 单格点按标记完成；支持行、列、区域和当前色号批量完成/撤销。
- 每次修改即时更新内存状态；按短间隔、进入后台和退出页面批量持久化，异常退出后恢复到最后一个完整进度块。
- 显示总进度、当前板进度、当前色号进度和预计剩余颗数。
- 完成图纸前提示未标记格数，但允许用户确认“实体已完成”。

#### 5.3.4 相近色与替换

- “修改图纸—替换色号”支持全图、选区、指定豆板三种范围。
- 临时辅助替换与永久设计替换分开：临时替换只改变辅助显示，完成后自动恢复原 SKU；永久替换改变用量和库存计算。
- 相近色推荐综合：色差、品牌/系列兼容、库存是否足够、替换后整体颜色数。
- 推荐列表展示色差等级、库存影响和样例对比，由用户确认。

#### 5.3.5 自动镜像

- 支持水平、垂直镜像与 90° 旋转。
- “仅查看镜像”不改变原图；“应用到图纸”生成新版本并重新计算坐标。
- 镜像状态需贯穿高亮、分板、导出和出库，不得出现显示与统计不一致。

### 5.4 补豆与出库

#### 5.4.1 图纸完成出库

- 路径：图纸详情 → 更多操作 → 完成并出库。
- 出库前展示每个 SKU 的需求、现存、出库后余额和异常项。
- 支持三种处理：正常扣减；不扣库存并记录原因；部分扣减并生成缺口。
- 同一图纸版本只能完成出库一次；重复点击返回原出库单，不重复扣减。
- 撤销完成状态时通过冲销单恢复库存和制作状态。

#### 5.4.2 阈值补货清单

- 支持全局默认阈值（例如 7000）和单色号阈值覆盖。
- 建议补货量可选：补至阈值、补至目标库存、覆盖所选图纸缺口、自定义。
- 清单分为：立即采购、在途可覆盖、到货后仍不足。
- 复制格式可配置为“色号 数量”，并包含品牌/系列避免歧义。

#### 5.4.3 本地补豆文本解析

- 用户粘贴自然语言、客服回单或订单文本。
- 系统使用内置色卡字典、分隔符规则和正则语法解析品牌、系列、色号、数量、到货状态和备注，逐项显示匹配结果。
- “未到货”建立采购批次与在途量，不计入现存量；“到货”生成入库流水。
- 后续确认到货时从采购批次一键入库，保持订单与流水关联。
- 无法匹配或重复的色号必须人工确认后才能提交。

### 5.5 提前计算消耗

- 图纸列表支持多选、全选当前筛选结果和加入“制作清单”。
- 聚合相同 SKU 的总需求，并考虑已预留数量。
- 结果字段：SKU、需求、现存、预留、可用、在途、现货缺口、预计缺口。
- 视觉语义：
  - 绿色：现货足够；
  - 黄色：现货不足但在途可覆盖；
  - 红色：即使到货仍不足；
  - 灰色：色号未映射或数据不完整。
- 支持从结果生成预留单或补货单；预留单取消时释放库存。
- 任何负数必须带字段名和说明，不使用括号负数表达多种状态。

### 5.6 相近色自动建议

- 当某 SKU 缺货时，列出同系列优先、跨系列次之的候选。
- 默认不自动应用；用户可逐项或批量确认。
- 候选必须满足尺寸兼容；不同材质、透明、夜光等特殊属性默认不混替。
- 替换预览显示受影响格数、图纸视觉变化、替代后库存和剩余缺口。
- 保存替换决策到图纸版本历史，可一键恢复。

产品决策：这里的“自动替换”指自动生成候选和替换预览；应用动作必须由用户确认。即使提供“一键应用全部建议”，也必须先展示受影响格数、库存变化并创建可撤销的新版本，不进行静默修改。

### 5.7 在线图纸库与作品管理

- 内置 50–100 张已许可启动图纸；在线目录扩展内容数量，首次安装或离线时仍可浏览启动集。
- 在线条目包含标题、作者/授权来源、许可、标签、尺寸、颜色数、豆数、难度、色卡版本、预览、内容版本和下载大小。
- 在线发现支持推荐、最新、分类、关键词、尺寸、颜色数、难度、色卡和本地库存可拼状态筛选。
- 搜索、收藏和筛选结果在设备端完成；收藏属于本地用户数据并进入备份。
- 下载流程显示排队、进度、暂停、重试、校验、安装、更新、已下架和不兼容状态。
- 已下载内容可离线打开；开始制作或编辑时创建独立本地图纸版本，远端更新和下架不静默修改用户项目。
- 状态：收藏、已下载、待制作、制作中、已完成、归档。
- 作品可关联完成照片、制作耗时、实际用量差异和备注。
- 详情页展示作者、来源、许可和联系入口；发布端保留权利链，下架通过显式撤回清单处理。
- 用户私有导入默认不公开；1.0 不开放投稿、评论或社交。

## 6. 关键业务规则

1. 库存余额由已生效流水汇总得出，不允许绕过流水直接修改。
2. 任何图纸用量都以当前已确认版本的有效网格为准。
3. 图纸编辑后生成新版本；已出库版本不可被静默覆盖。
4. 在途库存不参与实际出库，只影响预计缺口。
5. 预留库存不改变现存量，但降低可用量。
6. 跨品牌同名色号不是同一 SKU。
7. 数量均为非负整数；导入小数、负数或超上限数据时拒绝并提示具体行。
8. 所有批量提交均先预览、再确认、后写入，并返回可追踪单号。

## 8. 异常与空状态

- 无库存：引导初始化色卡、批量录入或导入模板。
- 无图纸：提供相册导入、内置启动图纸、在线图纸库和空白创作。
- 链接不可解析：显示来源、原因和继续使用截图/文件入口。
- OCR 不确定：高亮低置信度项，不猜测提交。
- 网格不齐：显示四角/边缘误差和重新校准入口。
- 库存不足：保留操作上下文，允许生成补货单或部分出库。
- 备份导入冲突：先预览差异；库存流水按唯一记录号去重，图纸冲突生成副本。
- 离线：显示内置启动集、上次成功目录、收藏和已下载图纸；在线新内容首次下载不可用，但全部核心创作能力继续工作。

## 9. 无障碍与易用性

- 不只靠颜色表达库存/进度状态，同时使用文字、图标和纹理。
- 支持动态字体、VoiceOver、深色模式、减少动态效果。
- 关键点击区域至少 44×44 pt；高亮对比度满足 WCAG 2.2 AA 目标。
- 对色觉差异用户提供色号文字、符号模式和自定义高亮色。
- iPad 支持横屏、分屏和键盘快捷操作；制作模式支持屏幕常亮开关。

## 10. 本地诊断指标与反馈

- 指标只在本机汇总，用于用户主动导出的诊断报告；默认不传输。
- 导入漏斗：开始导入 → 获取图片 → 网格校准 → 识别完成 → 校对完成 → 保存。
- 制作：开始会话、模式切换、进度、恢复、完成、出库。
- 库存：入库、盘点、缺货、补货单、在途转入库、冲销。
- 质量：OCR 低置信度率、网格差异率、人工修改率、解析失败来源。
- 诊断报告不包含原始图纸、库存备注、剪贴板全文或外部 URL；用户导出前可预览字段。

## 11. 版本规划

| 阶段 | 目标 | 主要交付 |
|---|---|---|
| Sprint 0（2 周） | 定义与验证 | 色卡/图纸样本、低保真原型、数据模型、识别 PoC、在线内容包和目录契约 |

实际排期取决于识别 PoC、在线内容规模、发布流水线和团队人数；上述为 1–2 名 iOS、1 名内容/平台工程师、1 名设计/产品并行的粗估。首版在线库采用静态目录和 CDN，不含账号、社交或运行时微服务。
