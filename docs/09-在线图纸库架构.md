# 在线图纸库架构

文档版本：0.1  
首版形态：公开只读目录 + 内容寻址对象存储/CDN + 本机索引与离线缓存

## 1. 产品边界

在线图纸库提供：

- 推荐、最新、分类、关键词搜索和条件筛选。
- 图纸详情、作者/来源、许可、尺寸、颜色数、豆数和难度。
- 缩略图/预览图按需加载。
- 下载、取消、重试、更新、删除和离线打开。
- 本地收藏、下载记录、制作状态和库存可拼判断。
- 内容版本、下架和兼容性提示。

首版不提供账号、评论、点赞计数、投稿、关注、聊天、云端收藏或实时协作。

## 2. 最小可行部署

```text
受控内容源
    │
    ▼
校验/打包/许可门禁流水线
    ├─ 生成 catalog-version.json
    ├─ 生成分页目录片段
    ├─ 生成内容包与 SHA-256
    └─ 生成撤回清单
    │
    ▼
对象存储（不可变对象）
    │
    ▼
CDN
    ├─ /catalog/latest.json        短缓存、ETag
    ├─ /catalog/{version}/...      不可变长缓存
    ├─ /packages/{sha256}.bundle   不可变长缓存
    ├─ /assets/{sha256}.image      不可变长缓存
    └─ /revocations/latest.json    短缓存、ETag
```

1.0 不需要运行时应用服务器、Redis、搜索集群或用户数据库。目录元数据在设备下载后建立本地索引，搜索和筛选在本机执行。

## 3. 内容模型

### 3.1 CatalogEntry

| 字段 | 说明 |
|---|---|
| id | 稳定图纸 ID，不随版本改变 |
| version | 图纸内容版本 |
| title/localizedTitles | 标题与本地化标题 |
| author/source | 作者、来源与展示署名 |
| license | 许可 ID、文本链接、署名要求、有效状态 |
| tags/category | 分类和筛选标签 |
| rows/columns | 图纸行列 |
| beadCount/colorCount | 总豆数和颜色数 |
| paletteRefs | 兼容色卡版本 |
| difficulty | 统一枚举和计算版本 |
| thumbnail | 内容哈希、尺寸、字节数、MIME |
| preview | 内容哈希、尺寸、字节数、MIME |
| package | 内容哈希、字节数、格式版本、最低 App 版本 |
| publishedAt/updatedAt | 发布和更新时间 |
| status | published、withdrawn、deprecated |

### 3.2 内容包

逻辑结构：

```text
manifest.json
pattern.matrix
usage.json
license.json
preview-reference.json
checksums.json
```

- `manifest.json` 定义格式版本、图纸 ID/版本、行列、色卡依赖和文件列表。
- `pattern.matrix` 与本地图纸矩阵使用同一格式。
- `usage.json` 是可重建缓存，安装时必须与矩阵重算结果核对。
- `checksums.json` 包含包内每个文件的 SHA-256 和字节数。
- 包解开后的文件数、总大小、压缩比和路径深度有硬上限，防止资源炸弹和路径穿越。

## 4. 版本与内容寻址

- 内容资产和包以 SHA-256 为路径身份；相同内容只保存一份。
- 目录版本单调递增；`latest.json` 只指向一个已完全发布的不可变版本。
- 新目录先上传所有资产和目录片段，校验可读后最后更新 `latest.json`。
- 客户端只有在新目录完整下载并校验后才原子切换，失败继续使用旧目录。
- 图纸更新产生新内容哈希；已下载旧版本保留到用户完成项目或主动删除。
- 用户创建的本地副本固定引用创建时版本，不被远端更新静默修改。
- 频道指针、目录 manifest、图纸 manifest 和撤回指针/清单必须使用 Ed25519 分离签名；缺签名、未知 key、签名无效或摘要不符均拒绝。

## 5. 客户端目录策略

### 5.1 启动

1. 立即加载本地目录缓存和首页快照，不等待网络。
2. 距离上次检查超过 6 小时且网络可用时，在后台对 `latest.json` 发条件请求。
3. 未变化时保持缓存；变化时下载新目录片段并校验。
4. 原子替换本地目录索引，通知可见页面做差量更新。

### 5.2 搜索与分页

- 首版目录目标 ≤ 5,000 条，元数据压缩包目标 ≤ 10 MB。
- 本机索引字段：标题、标签、作者、分类、行列、颜色数、豆数、难度、发布时间。
- 列表 UI 采用 30 条逻辑页；本地索引查询返回游标，不一次构造全量视图模型。
- 搜索输入防抖 250 ms；新查询取消旧任务。
- 排序必须稳定：主字段相同后按 `publishedAt`、`id` 排序。

## 6. 下载与离线缓存

### 6.1 状态机

`notDownloaded → queued → downloading → verifying → installed`  
失败状态：`paused、failed、incompatible、revoked`。

每个内容哈希只有一个状态机。页面离开不取消用户主动下载；预取任务可以取消。

### 6.2 缓存分层

| 层 | 内容 | 策略 |
|---|---|---|
| L0 内存 | 当前页面缩略图、目录查询结果 | 成本限制 + 内存警告清空 |
| L1 磁盘资产 | 缩略图、预览图 | SHA-256 命名，LRU 淘汰 |
| L2 已下载图纸 | 用户主动下载的内容包 | 默认固定，不自动淘汰 |
| L3 内置启动集 | 随 App 的少量图纸 | 只读，不淘汰 |

缓存记录存储哈希、类型、字节数、最后访问、引用计数、固定状态和校验状态。损坏内容视为缓存未命中并重新下载。

在线下载状态拆为四个字段：收藏关系、下载意图、安装状态、实际包是否存在，不能使用单个“已下载”布尔值。用户固定下载包位于 Application Support，属于完整备份内容；缩略图和预览仍是可重建缓存。

### 6.3 磁盘规则

- 缩略图/预览缓存默认上限 300 MB。
- 用户主动下载内容单独统计，不自动清除；设置页展示占用并允许批量删除。
- 可用空间低于 500 MB 时停止预取和新缓存；用户主动下载前显示空间不足。
- 临时下载与正式缓存位于同一文件系统，校验后原子移动。

派生图片缓存键使用 `assetHash + transformVersion + pixelSize + scale + colorSpace`，避免同一显示结果重复处理；哈希在下载流中增量计算，避免下载完成后再整包读盘。

## 7. 缩略图与预取

- CDN 提供固定尺寸变体或发布流水线预生成 256/512/1024 px 资源，客户端不下载原图再缩小。
- 首屏只请求当前可见项和下一屏，滚动方向改变时取消无用预取。
- 同一哈希请求合并；内存解码尺寸匹配显示尺寸，避免保留全分辨率位图。
- iPad 多栏预取窗口可大于 iPhone，但受统一并发和内存预算控制。
- 内存缩略图预算：iPhone 48 MB、iPad 96 MB；收到内存警告立即清空可重建位图。
- 网络并发：元数据最多 4、内容包最多 2、缩略图最多 4；低电量、严重热状态或后台时降低并发并暂停预取。

## 8. 完整性与安全

- 所有请求使用 HTTPS；客户端只访问配置的 CDN 主机。
- 校验 HTTP 状态、MIME、Content-Length、下载上限和 SHA-256。
- 频道指针、版本目录 manifest、图纸 manifest、撤回频道和撤回清单强制使用 Ed25519 分离签名；签名覆盖实际下载原始字节，签名私钥与 CDN 凭据分离。
- 公钥随 App 内置；签名元数据包含 `algorithm`、`keyID`、被签文件 SHA-256 和签名值。密钥轮换通过旧根密钥签名的新 keyring 或 App 更新完成。
- 不信任压缩包文件名；解包目标由 manifest 中的逻辑 ID 映射，拒绝绝对路径和 `..`。
- 包格式、文件数量、展开大小、单文件大小和压缩比均有限制。
- 目录文本作为普通文本显示，不允许注入 HTML 或远程脚本。

## 9. 许可、发布与下架

每条内容必须具备：权利主体、许可类型、授权范围、署名文本、原始证据引用、审核人、审核时间和到期日（如有）。缺任一必填项不得发布。

发布状态：draft → reviewed → published → withdrawn。

独立撤回频道 `/revocations/stable.json` 可紧急更新并带分离签名；它指向一个不可变且已签名的撤回清单。撤回清单包含图纸 ID、版本、原因类别、动作和生效时间：

- `hide`：停止新展示和下载，已下载内容保留但显示状态。
- `revoke-cache`：客户端下次联网后移除在线库缓存；用户基于该图纸创建的项目按许可政策处理并明确提示。

具体下架动作由内容许可政策确定，技术层只执行声明，不自行推断。

## 10. 可观测性

首版不上传个人行为。服务侧只使用 CDN/对象存储的聚合请求、错误、流量和缓存命中指标。客户端保留本机诊断：目录更新时间、失败阶段、HTTP 状态类别、校验失败和缓存占用，用户可主动导出。

## 11. 降级策略

| 故障 | 用户体验 |
|---|---|
| 离线 | 显示已缓存目录、内置启动集和已下载图纸 |
| latest 请求失败 | 保留旧目录，不弹重复错误 |
| 新目录损坏 | 回退旧目录并记录本机诊断 |
| 缩略图失败 | 占位图，不阻塞文字列表 |
| 内容包失败 | 保留详情和重试，不创建本地项目 |
| 版本不兼容 | 显示最低 App 版本，不尝试解析 |
| 内容下架 | 从在线结果隐藏，并按撤回动作处理本地缓存 |

## 12. 从静态目录升级动态 API

满足任一条件才启动第二阶段：运营图纸超过 5,000；目录压缩后超过 10 MB；搜索 P95 超过 150 ms；需要运营实时排序；需要多语言高级搜索。10,000 条仅作为客户端容量压力验收，不代表首发运营规模。

升级后新增无状态只读 Catalog API 和关系数据库，但对象资产、内容哈希、包格式、CDN、本地缓存与离线流程保持不变。频道指针增加 `sourceMode`；动态数据库成为唯一发布真值，应急静态快照由同一发布版本生成。客户端按频道只选择一种来源，不合并两者结果。

## 13. 性能预算

| 场景 | P95 目标 |
|---|---:|
| 缓存目录首屏 30 条 | ≤ 300 ms |
| 冷网络首屏（20 Mbps、RTT 100 ms） | ≤ 1.8 秒 |
| 1 万条目录本地搜索 | ≤ 150 ms |
| 10 MB 包下载+校验（同等网络） | ≤ 7 秒 |
| 50 MB 包哈希 | ≤ 1.5 秒 |
| 50 MB 包解包+结构校验+原子安装 | ≤ 4 秒 |
| 解包额外峰值内存 | ≤ 64 MB |
| 离线打开 120×120 / 240×240 | ≤ 1.0 / 1.5 秒 |

列表保持 55–60 FPS，不得连续 5 秒低于 45 FPS。可见缩略图和用户主动下载优先于下一屏预取和目录刷新；同一哈希的并发请求必须合并。
