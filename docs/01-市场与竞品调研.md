# 市场与竞品调研

生成日期：2026-08-27  
调研方式：核对中国区/海外 App Store 产品页、产品官网和 Apple 官方文档；功能以公开页面当前可见描述为准，未安装逐项实测的能力标记为“公开宣称”。

## 1. 结论摘要

常见拼豆应用大致分为四类：图片转图纸、像素画编辑、拼制辅助、库存/补货管理。多数产品只覆盖其中一至两类；较新的产品开始覆盖“图纸—库存—制作—补货—归档”完整流程。

本项目的机会不在于再次提供一个简单的图片像素化工具，而在于：

1. 用可校对的识别流程导入社交平台图纸或本地图片。
2. 让库存台账与图纸用量实时关联，拼前判断、拼后扣减。
3. 为真实拼制过程提供分板、辅助线、多色高亮、进度保留与镜像。
4. 把补货阈值、在途库存、替代色和批量消耗计算统一起来。

## 4. 用户需求推导

### 4.1 高频基础需求

- 生成或导入可拼的网格图纸。
- 识别并统一到具体品牌、系列和色号。
- 精确统计每种颜色需要多少颗。
- 拼制时减少漏拼、错位、串色和重复计数。
- 保存项目和制作进度。

### 4.2 尚未被稳定解决的需求

- 入库、出库、盘点、撤销和纠错都可追溯。
- 同时选择一组图纸，计算总用量与缺口。
- 区分现货、已预留、已下单未到货、可用库存。
- 导入带色号的现成图纸时，提供“自动识别 + 人工校对”而不是黑盒结果。
- 对近似颜色给出可解释的候选，而非直接静默替换。
- 大图在手机与 iPad 上保持流畅，且能按实体豆板分区执行。

## 5. 建议差异化

1. **可信台账**：任何库存变化都来自交易流水；不直接覆盖余额，盘点差异也生成调整记录。
2. **可校对识别**：图例区、网格、颜色区域和总颗数分别识别，并给出置信度、差异提示和手动修正入口。
3. **在途与预留**：消耗计算同时显示现货缺口和“含在途预计缺口”，避免括号负数语义不清。
4. **真实拼制模式**：按豆板、按颜色、边框优先、自选多色四种模式共享同一进度。
5. **批量项目规划**：系列/清单级汇总用量、预留库存、采购单和完成后批量出库。
6. **本地创作 + 在线内容**：在线图纸库负责发现和下载；图片分析、OCR、项目、库存、统计、补豆文本解析和制作均在设备处理和保存，已下载图纸离线可用，并通过用户主动导出的备份文件迁移数据。

## 6. 商业与内容边界

- 启动图纸和在线图纸库只使用原创、获授权或公共领域内容；第三方 IP 图纸必须有可追溯权利链、署名、许可期限和显式下架机制。
- 若开放用户投稿，需提供内容过滤、举报、屏蔽和联系方式。Apple 对用户生成内容有明确审核要求。
- 社交平台链接导入应采用官方允许的分享方式、公开接口或用户主动提供的图片；不同来源作为可替换适配器，避免核心流程依赖某个平台页面结构。
- 颜色近似值受屏幕、光线、相机和批次影响，替换建议必须展示原色/候选色、色差和库存影响，并由用户确认。
