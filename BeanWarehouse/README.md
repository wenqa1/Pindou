# 豆仓独立产品

豆仓是从“豆图”中抽离出的库存管理产品，首期交付两个独立安装形态：

- `BeanWarehouseiOS/`：iOS/iPadOS 16+ IPA，离线优先，Core Data/SQLite 保存在 App 沙盒。
- `BeanWarehouseNAS/`：飞牛 OS Docker Compose 应用，SQLite 保存在 NAS 挂载目录，通过浏览器访问。

两个应用不共享数据库文件，也不在首版自动同步。它们按同一 SKU、流水方向、正整数数量和幂等键契约处理库存，后续通过用户确认的导入/导出包或配对同步来连接。

## 当前功能

- 入库、出库、盘点增减和冲销的账本方向模型。
- SKU 按品牌、系列、色号三元组区分；同色号跨品牌不合并。
- 可用量从已生效流水重建；独立端的手工出库不会超过可用量。
- 低库存阈值、库存汇总、色号详情和流水历史。

## 数据边界

| 位置 | 数据真值 | 同步状态 |
|---|---|---|
| iOS IPA | `BeanWarehouse.sqlite` | 仅本机 |
| 飞牛 OS | `/data/bean-warehouse.sqlite` | 仅 NAS |
| 豆图 | `PindouApp.sqlite` | 仅本机 |

“豆图”与独立豆仓共用代码，不共享用户数据。任何跨端同步在实现前必须定义冲突策略、设备身份、加密密钥和备份恢复路径。
