# 拼豆 iOS 应用项目文档

项目暂定名：**豆图**（正式立项前需完成名称与商标检索）。目标为 iOS/iPadOS 16+ 的 iPhone/iPad 通用应用，重点适配 iPad。识别、库存、统计、文本解析和制作均在本机完成；在线图纸库负责内容发现与下载，已下载图纸离线可用。不接入通用大模型或云端推理。本仓库包含产品文档、工程骨架、AppShell 和 Codemagic 构建配置，尚未产生 IPA。

## 产品一句话定位

面向拼豆爱好者的 iPhone/iPad 一体化工具，将图纸获取与识别、辅助拼制、豆子库存、消耗核算、补货和作品归档连接成一个可追溯闭环。
